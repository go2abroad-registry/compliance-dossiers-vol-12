注资与解冻路径: 根据1993年《消防预防条例》所颁发的消防安全证书（适用于少于60人的低 occupancy 商业场所，包括疏散通道及应急照明的检查）；符合Class E2商业用途的建筑控制结构荷载证书；以及根据《工作场所健康与安全条例》（第197章）所颁发的职业安全与健康许可，确认急救设施、电气安装安全及卫生设施配置比例为每20人设1个卫生间。

实缴资本规则: 法律未规定最低实缴资本；通常采用面值为100英镑，分为100股每股1.00英镑的普通股；注册机构不要求设立托管账户、资本保证金或银行证明书。

支持身份选举表单

无论是直布罗陀还是开曼群岛，都不提供美国式的“勾选式”或混合模式不匹配选举制度。直布罗陀允许符合条件的关联公司之间进行法定集团优惠转让选举、单边或条约双重征税优惠选举，以及根据2010年所得税法进行的扣除与分配选举；而经合组织BEPS行动2所要求的反混合规则则是强制性的，无法被选择取消。开曼群岛的法律仅规定《公司法》第6(1)条中的免税公司声明，而非传递税选举制度。

流转税 (VAT / GST) 与出口 0% 零税率

标准增值税/流转税率

直布罗陀不征收增值税、销售税或使用税；其唯一的国内间接税是《海关关税条例》规定的直布罗陀进口税，该税仅适用于实物商品，不适用于数字无代码网站构建服务。当向欧盟最终消费者提供B2C数字服务时，可能单独产生欧盟增值税义务。

强制登记营业额门槛 (Nexus)

直布罗陀境内：不适用；不存在增值税/GST的注册门槛。欧盟OSS（非欧盟成员国卖家）：无免征门槛；一旦通过选定的欧盟成员国的非欧盟成员国OSS方案向欧盟消费者提供首次欧元金额的B2C数字服务，即必须进行强制注册。向在欧盟设立的接收方提供网页模板/许可服务的B2B供应行为，实行反向征税，无需供应商进行增值税注册。若Paddle或Stripe作为商户记录方，则支付平台实体需承担底层增值税/销售税结算的法定责任。

跨境出口 0% 零税率申报条件

在直布罗陀，数字服务并不适用关税：SaaS/网络编辑工具访问权限、模板许可、托管服务以及低代码应用程序输出均不在直布罗陀进口税的涵盖范围内，且出口时无需缴纳直布罗陀增值税。根据欧盟增值税规定，B2B数字产品在客户所在地进行反向征税，而B2C数字电子服务则按客户所在成员国的税率征税，不存在0%的出口税率。实物商品只有在离开直布罗陀海关时提供有效的运输文件后，才符合免税出口的条件。

外汇管制与央行政策诊断

经常项目兑换自由度

直布罗陀以与英镑（GBP）等值的直布罗陀镑（GIP）作为法定货币，英镑（GBP）同样为法定货币，并可自由兑换用于经常项目和资本项目交易。开曼群岛采用以每1开曼群岛元（KYD）兑换0.80美元的开曼群岛元（KYD）汇率，美元作为惯例货币并可完全自由兑换。直布罗陀和开曼群岛均无外汇管制措施，限制经常项目汇款、股息分配、资本返还或利润汇出。开曼群岛的公司结构在税收上保持免税地位，直布罗陀则对非居民控股公司实行属地税收制度；利润汇出自由进行，但需符合反洗钱（AML）资金来源核实要求。

出口外汇强制结汇要求

在直布罗陀或开曼群岛，没有关于出口收益上缴时间或强制转换比例的规定。出口收入可以保留以外币形式，按市场汇率进行转换，或者直接用于结算，但须遵守《反洗钱条例》和《经济实体（国际税务合规）条例》中的记录要求。

央行监管: 直布罗陀金融服务委员会（GFSC）与直布罗陀货币局在英国 Crown Dependencies 框架下协同运作；开曼群岛货币局（CIMA）是开曼豁免公司注册地的主管机构。

离岸数字新锐银行 / EMI 白名单

Cross-border EMI / Fintech rails 适配度: High

跨境清算通道与结算适配

来自英国/欧盟投资者的资本注入应通过SWIFT MT103支付至直布罗陀运营账户，使用英国/OECD支付报告分类中的目的代码“A.01”（资本投入）以及软件服务预付款的目的代码“C.70”。每笔汇款必须附带董事会决议、已发行股份证书、认购协议以及符合经济特点的资金来源声明。对于开曼方面托管资金的拨付，应使用SWIFT MT103并注明“开曼行政用途”目的，通过英国代理行账户向直布罗陀进行次级贷款或股权投入。验证流程遵循第五号反洗钱指令及开曼反洗钱法规；在财库政策中应明确拒绝所有与数字资产相关的资金流入。SaaS平台的费用通过SWIFT MT103企业或商业支付方式从直布罗陀运营账户中扣除，其中“软件许可费”使用代码‘B.70’，而“特许权使用费”则使用代码‘B.81’。这些款项被转交给Stripe或Paddle作为记名商户的信托账户。关于计算、存储和内容传递方面的批发支付，则通过标准的SWIFT MT103或MT202方式进行，并需以商业信用证作为担保，尤其是当供应商需要有抵押付款保证时。对于出口服务的买方支付，则可以按照商户流程进行；财务部门必须在开曼控股公司和直布罗陀运营公司之间保持独立的账本对账。对于价值较高的软件许可支出（超过1,000,000美元），建议采用SWIFT MT103支付指令，同时由英国或瑞士顶级银行出具经过严格审核的商业信用证确认文件。通过直布罗陀许可银行或英国授权支付机构进行的即期英镑/美元及欧元/美元对冲交易以英镑/美元和欧元/美元为标的、期限最长为12个月的即期外汇远期交易，通过主要经纪商或主要英国清算机构进行交易用于亚太地区或拉美地区客户交易的非交割远期（NDFs）的 exotic 货币对，仅在符合ISDA主协议及英国EMIR报告要求的前提下使用。通过开曼银行或全球交易商以开曼美元（KYD）与英镑/美元（GBP/USD）进行的交叉货币互换，仅限于现金管理的头寸匹配目的。零成本项圈和参与式远期交易，用于保障最低 SaaS 收入转化门槛
