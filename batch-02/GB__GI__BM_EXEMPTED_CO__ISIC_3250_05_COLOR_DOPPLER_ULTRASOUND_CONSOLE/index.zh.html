主管税务局

直税由乔治城所得税专员、乔治城政府（所得税办公室、电子税务门户）负责；公司注册由乔治城公司登记处负责；英国增值税及出口管制则通过英国政府门户/海关申报服务由英国税务海关总署（HMRC）负责。门户链接：https://www.gibraltar.gov.gi/income-tax 和 https://www.gov.uk/topic/vat

电子政务申报门户

步骤1：根据《2014年直布罗陀公司法》提交外国公司注册文件（FC1表格），以获得直布罗陀注册的外国公司编号。步骤2：在建立永久机构或开始从事直布罗陀源经济活动后28天内，向直布罗陀所得税局提交10号表格，以获取税务参考号码/直布罗陀TRN。步骤3：对于英国增值税，作为非设立税源的免税公司，必须向HMRC申请VAT1登记（或通过政府网关在线办理），并提供巴麦尼亚公司注册证明、直布罗陀外国公司编号以及英国交易凭证；HMRC会颁发GB增值税注册号。步骤4：对于所有出口业务，如果从英国出口，该实体必须使用经济运营商注册与识别编号（EORI编号，GB/EORI）进行英国海关注册。

默认税务分类与身份选举

默认税务归类

税收豁免区。百慕大豁免公司可免交百慕大所得税，并保持此状态；在直布罗陀，如果没有中央管理或直布罗陀常设机构，该公司被视为非居民外国公司，其所得税仅针对来自常设机构的利润征收。它并非传递实体，因此对于海外及非直布罗陀业务而言，无需缴纳直布罗陀实体级所得税。

支持身份选举表单

没有美国式的选择式选举机制。百慕大法律允许被豁免的公司申请税务豁免证明，并根据要求申请税务居民声明，但公司的默认豁免状态无法被打破以符合美国的混合模式。2010年直布罗陀所得税法允许外国公司选择被视为直布罗陀税务居民，前提是中央管理和控制权在直布罗陀进行，这将使该公司需缴纳全球收入的12.5%的公司税。在直布罗陀的受控制外国公司和英国规则下，跨境集团结构中可能存在混合式选择，但在百慕大和直布罗陀都没有直接的法定选择式或忽略实体选择机制。该实体应依靠条约和本地税收协定来保障其豁免状态。

强制登记营业额门槛 (Nexus)

英国增值税应税营业额门槛：任何过去12个月期间累计超过90,000英镑；未设立企业的应税主体进行任何英国应税供应时，必须立即登记，没有具体门槛限制，除非该服务属于反向收费类别，且需符合英国登记门槛。直布罗陀没有增值税起征点；在欧盟/英国增值税统一之前，仅适用直布罗陀的海关进口/出口关税，而样品和一次性医疗用品则享有免税优惠。

跨境出口 0% 零税率申报条件

根据1994年英国增值税法（VAT Act 1994），一家注册于英国、在百慕大享有豁免资格的公司，可对从英国物理运输出口至非英国/北爱尔兰目的地的便携式相控阵医学诊断扫描仪（HS 9018.12 / ISIC 3250）实行零税率，前提是出口商持有并妥善保存充分的商业证据（出口申报、离境证明、运输单据，以及适用情况下客户的收据）。若货物直接从直布罗陀出口至第三国，则该供应行为不属于英国增值税的征税范围，而非零税率处理，相关退税申请须通过直布罗陀海关关税制度或通过境外增值税退税程序提出。出口至海外医疗接收方的医学影像服务，若其受益方位于英国境外且接收方属于英国境外，也可视为服务出口并适用零税率；涉及集团内部离岸销售的，须提供转让定价文件，以避免被认定为虚假零税率的挑战。

  • 海关出口申报（英国CDS或直布罗陀海关申报；包含MRN和出口日期）
  • 提单或空运提单（须由承运人出具，注明出口商、收货人、起运地、目的地）
  • 入账证明或经认证的SWIFT MT103/MT950报文，证明全部出口款项已汇入出口方账户

英国并不强制要求使用电子发票，但针对增值税的“数字化税务”制度要求所有注册企业必须保存数字记录，并每季度通过经HMRC认可的兼容软件及MTD API来提交增值税申报；目前并未实施实时财务清算或连续交易控制机制。在英国，通过海关申报服务（CDS）使用 XML/EDM API 进行海关出口清关是必须的；在某些情况下，还需通过进口控制系统2（ICS2）提交出发前汇总申报以完成过境手续。在英国，无需对电子发票进行数字印章处理或立即获得政府批准。直布罗陀采用独立的、简化的海关申报系统，并不要求商业交易流程使用电子发票结算。

英国税务海关局（HMRC）可在4年征税期内（或故意隐瞒情况下最长可达20年）重新审查零税率出口业务，若证据不足，将要求立即偿还应缴的增值税，并自原申报日期起计收违约利息。根据2007年财政法案第24号附表规定的民事处罚，最高可处以所逃避增值税金额的100%；根据1994年增值税法第60条，责任为严格责任。伪造海关文件、倒签提单或使用循环外汇汇款的行为，将可能构成《2006年英国欺诈法》及《2011年直布罗陀欺诈法》下的刑事犯罪，罚款无上限，最高可被判处10年监禁；此外，还可能被吊销或取消EORI号码及英国增值税登记资格。直布罗陀税务局可对未按规定提交法定公司申报文件的行为，每次处以最高3000英镑的罚款，并在公司未真正从百慕大开展离岸业务的情况下，取消其免税公司地位。
