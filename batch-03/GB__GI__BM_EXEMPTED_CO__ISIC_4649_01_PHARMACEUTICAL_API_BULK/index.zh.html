在直布罗陀没有美国式的勾选式选举制度。根据2010年所得税法，可选择的选举方式包括：(1) 针对未汇回或未在直布罗陀产生的外国来源收入所提出的地域来源申报；(2) 集团福利选择，允许符合资格的75%集团公司之间共享亏损；(3) 资本津贴选择，包括集中处理和年度投资津贴申请；(4) 专利箱选择，对符合条件的知识产权收入适用5%的税率；(5) 金融公司选择，对符合条件的金融和许可收入适用7.5%的税率；(6) 没有混合不匹配选择，OECD混合不匹配规则适用于禁止过度扣除。所有选择均需在法定期限内向所得税专员提交书面通知。

流转税 (VAT / GST) 与出口 0% 零税率

标准增值税/流转税率

没有——直布罗陀不征收增值税、 GST或一般销售税。间接税收仅限于《海关关税条例》和消费税法规所规定的特定商品（如酒精、烟草、燃料、化妆品等）进口时的海关和消费税。属于HS第29章和第30章范围内的药品原料的跨境销售则不属于直布罗陀任何间接税收的适用范围。

强制登记营业额门槛 (Nexus)

不适用——没有增值税/ GST注册门槛。无论营业额大小，都必须遵守以下要求：(i) 所有商业海关经营者必须办理EORI登记；(ii) 对于进口或储存特定商品（如酒精、烟草、燃料）的情况，必须完成消费税/关税注册及担保手续。当地货币为直布罗陀磅。

跨境出口 0% 零税率申报条件

在严格的增值税定义下，零费率并不适用，因为直布罗陀不征收增值税/ GST。所有从直布罗陀出口的药品活性成分均自动属于直布罗陀间接税适用范围之外，因此实际税率为0%，且无需退税机制。为了维持这种税收中立的出口待遇，出口商必须证明：(1) 从直布罗陀进行的实际出口行为，且相关海关SAD出口声明已获得直布罗陀英国海关的认可；(2) 向非直布罗陀购买方销售的行为，可通过商业发票和合同予以证明；(3) 货物在合理时间内从直布罗陀运出。通常为90天。无需提交直布罗陀增值税/退款申请；好处是出口交易不会征收任何当地间接税。

  • 吉布提海关出口申报（单一行政文件/电子出口申报）获吉布提海关接受
  • 提单或空运提单显示直布罗陀实体为发货人，非直布罗陀籍收货人
  • 商业发票及详细装箱单（API描述，适用的HS编码2922/2933/3002，数量，国际贸易术语及金额）
  • 汇入汇款证明或SWIFT MT103/MT202报文，证明收到出口收入
  • 原产地证书（仅在主张优惠原产地待遇时需要；否则为可选）
  • 药品批发/原料药分销许可证（根据直布罗陀药品条例中的一般批发授权）及根据需要提供的目的地国家健康证书

在直布罗陀，没有实时财政结算、基于API的发票盖章功能，也没有强制性的电子发票制度。商业发票可以以纸质或电子形式开具。所有海关申报都必须通过直布罗陀海关单一窗口进行电子提交（该系统采用与英国CDS等效的处理方式）。纳税人必须为所得税和海关审计目的而保留发票及相关的出口文件，期限为六年。

直布罗陀海关与所得税专员联合审计API出口交易。处罚措施如下：（1）海关申报不实或逃避关税——最高可处以逃避关税金额三倍的罚款，适用法定罚款，并没收货物；（2）在税务申报中提供虚假陈述——最高可处以未缴税款100%的民事罚款，并按年利率15%计收利息；（3）欺诈性逃避关税的刑事处罚——最高可处以直布罗陀镑10,000的罚款及/或监禁；（4）若出口证据虚假、出口款项未在180天内汇回，或未满足经济实质及转让定价要求，则追溯收回税收减免、免税或来源地排除权益；（5）撤销药品条例批发许可证，并将其列入高风险反洗钱/监管名单；（6）每一份未申报的海关出口申报单，最低罚款为直布罗陀镑500。

外汇管制与央行政策诊断

经常项目兑换自由度

直布罗陀英镑可以按1:1的比例完全兑换为英镑。直布罗陀实行开放、自由化的外汇管制制度，对资本账户交易或经常账户支付没有限制。该地区没有单独的资本管制措施，向股东汇付利润在境内是不受限制的，但需经过FSC直布罗陀的反洗钱审核，以确认资金来源和实际所有权归属。对于由直布罗陀管理、属于百慕大豁免公司的企业来说，实际面临的障碍仅限于提供干净的结构性文件、符合要求的“经济实质”文件，以及证明该公司并非被列入黑名单或不合作的司法管辖区的居民。

出口外汇强制结汇要求

没有。直布罗陀不要求履行任何法定移交义务，也不规定必须进行的货币兑换比例，对于通过批发分销活性药物成分所获得的出口收入，也没有关于其回拨或兑换的期限。这些出口收入可以保留在原收汇货币中，无论是美元、欧元、英镑还是瑞士法郎，并且可以直接用于贸易结算或外汇对冲策略，无需经中央银行批准。

央行监管: 直布罗陀金融服务委员会（FSC 直布罗陀），与英格兰银行协同运作，作为直布罗陀镑（GIP）的发行机构，该货币与英镑（GBP）保持等值挂钩。

转让定价与经济实质

主文档/本地文档门槛: 在直布罗陀国内法中，并未设定关于本地文件/主文件准备的法定金额门槛；然而，为了做到合规，对于每一笔受控制的跨境交易，都需要同时提供相应的基准文件，建议每年向每个相关交易对手方披露100,000吉布亚尔的资金。对于集团收入达到或超过750,000,000欧元（约750,000,000吉布亚尔）的跨国企业集团，则必须遵守“国家별报告”要求；直布罗陀的最终母公司必须通过电子服务平台提交G-CBC表格。

经济实质审查范围: 适用情况：根据直布罗陀在2019年加入欧盟行为准则小组并符合经合组织实质要求的承诺，任何以直布罗陀为税务居民、具有国际业务导向的公司——包括重新注册于百慕大的免税公司，从事API批发分销业务——均须在直布罗陀证明其经济实质，具体包括：（i）公司决策与管理活动在直布罗陀开展；（ii）在直布罗陀拥有符合资格的办公场所；（iii）在直布罗陀拥有足够数量的全职员工；（iv）在直布罗陀拥有足够的年度运营支出；以及（v）核心创收活动（如采购、定价、合同谈判、开票、物流及分销决策）均在直布罗陀实施。该实质声明必须随每次公司所得税申报表一并提交；若未能提供充分证明，则将触发税率从5%上调至10%，丧失英国-直布罗陀税收协定的优惠待遇，面临声誉风险及可能被撤销公司资格的后果。

致命合规红线与董事个人责任

逃税 / 虚假报税

法定制裁: 根据2010年直布罗陀所得税法（经修订），欺诈性申报行为将面临高达所少缴税款的100%的罚款、法定利息、无限额罚款、最高7年的监禁、根据2015年犯罪所得法进行的财产没收命令，以及直布罗陀银行资产的扣押。

董事个人责任: 签署虚假财务报表或声明的董事及影子董事，若公司已资不抵债，将就税款相关的处罚承担连带及分别责任；他们还可能面临最高15年的董事资格取消、司法禁令以及欺诈性经营行为的监禁刑罚。
空壳公司 / 缺乏经济实质

法定制裁: 按全额10%的利率进行追溯重新评估，因不符合经济规定而处以罚款，根据2014年《公司法》必须强制终止业务，无法享受英国-直布罗陀双边协议福利，且由于在欧盟/OECD市场的负面公开上市情况，导致法定药品批发许可证及对应银行业务权限被撤销。

董事个人责任: 批准虚假实质声明的董事，将违反《2014年公司法》和《2010年所得税法》；他们将面临个人税务追缴、资格取消、旅行限制，以及根据《2011年破产法》被追究欺诈性经营的刑事责任。
转让定价 / 利润转移

法定制裁: 按照原始到期日适用法定利率进行合理化调整，最高可处以额外税额100%的税款处罚，并将超额支付重新定性为股息分配；若英国居民母公司控制了直布罗陀实体，则可能产生平行的英国受控外国企业（CFC）税务暴露。

董事个人责任: 签署虚假的TP日程表和财务报告的官员，除了要对公司承担责任外，还要自行承担责任；英国《反欺诈法》和民事处罚制度可适用于董事；涉及欺诈的调整行为可能引发基于引渡的起诉。
反洗钱/制裁违规（高风险药品原料药）

法定制裁: 根据《2015年犯罪所得法》（经修订）规定，洗钱行为可处以无限额罚款和最高14年的监禁；法定批发药品许可证将被撤销；吉布岛适用的联合国/欧盟/英国制裁框架将冻结相关账户。直布罗陀金融服务委员会的监管执行以及不利的反洗钱风险登记册记录。

董事个人责任: 董事被视为法定反洗钱官员；根据2019年反洗钱法规未能维持充分的反洗钱/反恐融资控制措施，将导致个人承担刑事责任、资产没收、旅行禁令，以及被禁止管理直布罗陀公司长达15年。
非法利润汇回 / 资本结构薄弱与股息剥离

法定制裁: 违反《2014年公司法》宣布的股息无效且可追索；超出限额的利息扣除不予允许，并被重新认定为利润分配；在确认存在税收协定滥用的情况下，视为分配的股息可能触发非居民股东的预提税评估；公司可能被注销，并附带资产追索令。

董事个人责任: 任何签署非法分配决议或资信证明的董事，须个人承担偿还该款项及利息的责任；此外，还将面临旅行禁令、资格取消以及根据2014年公司法可能被追究不当行为的刑事责任，最高可判处五年监禁。
