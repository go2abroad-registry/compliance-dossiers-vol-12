流转税 (VAT / GST) 与出口 0% 零税率

标准增值税/流转税率

直布罗陀不征收增值税/ GST；需缴纳直布罗陀海关税及进口消费税；根据《1994年英国增值税法》，如果相关企业在英国进行应税交易，则可能需要缴纳英国增值税；百慕大不征收增值税/GST，而是对进口商品征收海关税。

强制登记营业额门槛 (Nexus)

直布罗陀：无增值税起征点，因为不征收增值税。就直布罗陀所得税而言，凡在直布罗陀产生的应税收入均需进行征税评估；若公司已在直布罗陀设有常设机构或获得来源于直布罗陀的收入，则需进行税务登记。对于英国增值税（如因在英国设有机构或远程销售而适用），强制注册的营业额门槛为12个月内应税营业额达到90,000英镑。百慕大：无增值税起征点；进口货物和设备需按不同税率缴纳百慕大海关关税，且无一般销售税的注册门槛。

跨境出口 0% 零税率申报条件

由于直布罗陀不在欧盟增值税适用范围内，也没有增值税，因此B2B模式下的数字服务跨境供应（如网页抓取API和代理网关服务）无需缴纳直布罗陀增值税。如果该实体在英国注册，那么向英国以外的企业提供的数字服务可根据1994年《增值税法》第7A条及2019年《服务供应地修订条例》享受零税率待遇，前提是客户位于非英国国家，且供应的是电子服务，同时保留有效的出口证明。如果百慕大免税公司在其境内开展业务，则无需缴纳出口税或享受零税率，因为百慕大没有增值税。而向直布罗陀/英国B2C客户提供的软件/数据管道服务，如果该公司在英国注册，则可能需要按20%的税率缴纳英国增值税；否则则无需缴纳直布罗陀增值税。

外汇管制与央行政策诊断

经常项目兑换自由度

直布罗陀实行完全可兑换的离岸货币制度，对资本账户没有任何限制。直布罗陀镑（GIP）与英镑（GBP）保持1:1的固定汇率，两种货币可以自由流通互换。伯利兹豁免公司可自由向任何司法管辖区汇出利润、股息、特许权使用费及公司间结算，无需经过外汇管制审批或强制兑换。网络爬虫API出口根据国际货币基金组织BPM6分类属于经常账户服务（ISIC 6201 / NAICS 518210），因此完全可兑换，无需许可或托管。美元现金（USDC）及其他虚拟资产并非法定货币；然而，受直布罗陀金融监管局（GFSC）监管的实体可依据《金融服务（分布式账本技术）法案2021》进行相关资产的兑换。无需获得英国银行（Bank of England）或直布罗陀金融监管局（GFSC）的资本注入、利润汇回或股息汇出批准，仅需遵守FATCA/CRS报告要求以及《经济实质（公司）法》的相关合规要求。

出口外汇强制结汇要求

在英国和直布罗陀都没有投降义务。法定转换比例为0%，遣返时间则没有限制；来自跨境数据管道、API订阅及商业数据抓取服务的收益可以保留为英镑、吉布提先令、美元、欧元或任何可自由兑换的货币。唯一的行政要求包括：(i)通过服务银行进行准确的国际收支统计分类；(ii)提供证明按公平交易原则进行保留的转移定价文件；(iii)提供显示与保留余额相一致的收入生成活动的直布罗陀经济实体报告。

央行监管: 英国银行（BoE）对英国及其海外领地行使主权货币权力；直布罗陀金融服务委员会（GFSC）负责监管直布罗陀所有获许可的银行和虚拟资产服务提供商；直布罗陀政府（财政部，货币司）依据1934年货币票据法，发行直布罗陀英镑（GIP）纸币和硬币，其发行完全以1:1的英镑储备为基础，这些储备存于货币票据和硬币储备中。

电商与网关结算适配度: 受限介质。那些信誉良好的跨境电子货币机构——如Wise Business、Revolut Business、Airwallex、Currencycloud、Modulr等——可以接受由直布罗陀注册成立的运营公司，且该公司需具备可验证的本地业务实体。但每个电子货币机构的风险评估系统都会将百慕大的免税公司作为税务避风港司法管辖区标记出来，如果没有直布罗陀地区的董事、经审计的财务数据以及符合规定的信托代表，就会自动拒绝其注册申请。根据PSD2法规的法律限制，电子货币机构只能从事电子货币发行和支付服务；它们不能持有商业存款，而未经许可的百慕大实体则必须获得GFSC“电子货币分配协议”的批准才能运营。只有直布罗陀注册的运营实体才具有较高的注册可行性，百慕大的控股实体则不然；由直布罗陀指定的影子董事以及获得ICSI许可的公司秘书可以显著降低风险。

致命合规红线与董事个人责任

逃税及虚假陈述

法定制裁: 罚款金额为少缴税款的100%加上法定利息；经定罪则处以刑事罚款；撤销直布罗陀的注册。

董事个人责任: 董事及影子官员就税款不足承担连带及按份责任；一旦被定罪，将面临最高十年监禁及被禁止进入直布罗陀；法院可下令追回被挪用的利润。
空壳公司 / 缺乏经济实质

法定制裁: 强制注销与撤销登记；对每年10万英镑集中税的环境、社会与治理（ESR）评估；拒绝给予百慕大母公司参与豁免。

董事个人责任: 第234(7)条：最高可处以15年的禁止令；在未实质内容的情况下签发合规证书的个人责任；在资产位于境内的期间，实施民事扣押令和旅行限制。
反洗钱/反恐融资不合规及加密货币支付

法定制裁: 民事罚款最高可达每项违规25万英镑；刑事罚款及加密货币资产的没收；暂停关联支付实体所持有的金融服务业委员会许可证。

法定制裁: 税务机构可将转让利润调整至公允交易标准，以10%的税率重新计算应税利润，对未足额缴纳税款进行评估，并处以50%至100%的准确性罚款。
