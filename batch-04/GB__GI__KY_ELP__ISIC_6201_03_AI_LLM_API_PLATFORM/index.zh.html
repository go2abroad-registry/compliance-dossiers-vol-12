法定实缴资本与验资锁资账户流程 强制验资锁定

没有法定的最低实收资本要求。有限合伙人提供的出资额可在有限合伙企业协议中自由约定；作为豁免型有限合伙企业进行注册时，无需设立托管账户、进行资本验证或缴纳资本保证金。

注资与解冻路径: 无需办理民用防御许可。注册办公室/行政场所必须持有占用证明，并遵守《消防安全与应急程序规定》中的消防安全要求；建议对任何租赁的办公空间进行完整的电气和结构安全自我评估。

实缴资本规则: 没有法定的最低实收资本要求。有限合伙人提供的出资额可在有限合伙企业协议中自由约定；作为豁免型有限合伙企业进行注册时，无需设立托管账户、进行资本验证或缴纳资本保证金。

符合穿透性要求。ELP具有财政透明度；它并非实体级纳税主体，因此对该合伙企业本身不征收直布罗陀所得税。每个合伙人的收入部分将属于严格的地域范围，非居民合伙人仅对其在直布罗陀产生的收入征税。对于没有直布罗陀常设机构的离岸AI/LLM API收入，则无需缴纳直布罗陀所得税。

支持身份选举表单

在国内层面没有相关制度。直布罗陀不实行“选择式选举”制度，而ELP的传递性状态是必须的。外国合作伙伴可以在其所在国进行美国联邦式的“选择式选举”（表格8832）或类似程序以进行海外申报，但此类选举并不会改变直布罗陀国内的税收结果。目前没有适用于直布罗陀的混合不匹配选举制度；当透明与非透明分类之间存在差异导致双重免税或超额扣除时，可能适用OECD/英国的反混合规则。

流转税 (VAT / GST) 与出口 0% 零税率

标准增值税/流转税率

没有增值税/GST或一般销售与使用税制度；直布罗陀仅对特定商品征收进口关税和消费税，实行有限的间接税制度。

强制登记营业额门槛 (Nexus)

在整体经济层面并不适用。直布罗陀没有增值税/ GST营业额限制。那些进口或交易烟草、酒精或燃料等受消费税监管商品的个人，无论其营业额如何，都可能需要进行直布罗陀磅制的海关/消费税登记。而纯人工智能API服务收入则无需遵守此类要求。

跨境出口 0% 零税率申报条件

不适用。由于直布罗陀没有增值税/ GST，因此不存在零税率供应机制，也没有出口增值税退税制度，对于跨境人工智能 API 服务而言，也无需提供零税率的证明。离岸服务收入不属于直布罗陀间接税范围，根据 ELP 领土税制度，也不属于直布罗陀所得税范围，除非这些收入源自直布罗陀。在增值税管辖区经营的客户可能在当地需要缴纳反向征收的增值税。

  • 海关出口申报单/直布罗陀单一行政文件（SAD），仅适用于货物从直布罗陀的实际出口；对于AI API服务的提供无需提交。
  • 提单或空运提单，作为实物商品出口的运输凭证；纯数字服务无需提供。
  • 汇款证明或银行付款确认书，用于支持货物出口后境外资金回流及财务审计追溯。

在直布罗陀的国内发票业务中，没有实时财政清算、API清算、数字盖章或PEPPOL式电子发票结算的相关要求。标准的电子发票在记录保存方面是合法的。如果ELP或相关的英国机构单独注册英国增值税账户，那么“英国数字化征税”以及HMRC的电子申报/API规则将适用于该注册情况。

不存在增值税追回风险，因为无法获得增值税零税率退款。然而，通过虚假海关申报来获取关税减免或出口退税款的行为，将面临直布罗陀海关的处罚，包括没收货物、缴纳不超过货物价值三倍的罚款，以及因欺诈逃税而承担刑事责任。就所得税而言，故意不披露来自直布罗陀的应税利润，可能会面临高达100%的罚款，并根据所得税法进行追溯征税。离岸人工智能API运营商必须保留与业务相关的真实证据，以反驳关于永久机构或来源地的主张。

外汇管制与央行政策诊断

经常项目兑换自由度

直布罗陀对经常项目和资本项目交易均实行完全可兑换。对于利润、股息或资本的汇回，不存在外汇管制限制。直布罗陀镑（GIP）可按1:1的比例自由兑换为英镑（GBP），并允许开立外币账户。利润汇回的障碍很小，仅需符合一般公司文件要求，并取得直布罗陀所得税局的税务清关证明即可。

出口外汇强制结汇要求

没有法定的转让要求。出口商无需在任何期限内将外币收入兑换为吉普亚元或英镑。所有出口收入可以保留在外币账户中，也可以按照市场汇率自由兑换。

央行监管: 直布罗陀金融服务委员会（GFSC）与直布罗陀政府财政部协同工作；直布罗陀镑（GIP）由直布罗陀政府发行，并与英镑（GBP）保持等值挂钩。

Cross-border EMI / Fintech rails 适配度: High

可行性评级：中高。吉尔吉特拥有以《2019年金融服务法》为基础的渐进式金融科技监管体系，允许电子货币机构（EMI）由吉尔吉特金融监管局（GFSC）进行许可。境外数字电子货币机构（例如位于英国或欧盟的机构）可在吉尔吉特通过“互认”或本地许可方式运营，但必须遵守GFSC的反洗钱/反恐融资（AML/CFT）规定。对于风险较低的AI API平台而言，经许可的EMI可提供高效的跨境支付通道，但无法提供完整的银行服务（如贷款）。法律限制包括强制性许可要求、资本金要求（EMI需至少35万欧元）以及严格的反洗钱/客户身份识别（AML/KYC）程序。

转让定价与经济实质

主文档/本地文档门槛: 如果某一财年的关联方控制交易总额超过1000,000吉布亚尔，则需提供本地文件。如果合并集团收入至少为75亿吉布亚尔，则需提供主文件和各国报告。根据OECD低价值集团内部服务方法，也可提供简化版文件。

经济实质审查范围: 《2019年经济实体（公司与有限合伙企业）条例》适用于在直布罗陀开展相关业务的直布罗陀税务居民有限合伙企业，这些业务包括知识产权持有、分销和服务中心以及融资业务。纯股权形式的有限合伙企业则需满足较低的实体要求。该有限合伙企业必须在直布罗陀进行运营和管理，拥有直布罗陀内的实际经营场所和足够数量的员工，并在直布罗陀开展核心收入生成活动。非直布罗陀税务居民 olan有限合伙企业虽不属于ESR范畴，但不得虚假申报其税务居民身份，以避免违反实体要求。

致命合规红线与董事个人责任

逃税

法定制裁: 根据2010年所得税法，民事处罚可达逃税金额的150%，外加利息；根据2011年犯罪法，刑事责任包括按法定最高限额处以罚款，以及在被起诉定罪后处以最多七年的监禁。

董事个人责任: ELP普通合伙人和影子董事对逃避的税款需承担共同和个别责任；法院可以实施旅行禁令、资产冻结命令，禁止其担任董事长达十五年，或处以监禁。
空壳公司 / 缺乏经济实质

法定制裁: 根据《2019年经济实体（公司与有限合伙企业）条例》：首次违约将处以50,000吉特币的罚款；持续违约则每日处以1,000吉特币的罚款；年度违约罚款最高可达200,000吉特币；若连续两年不合规，将面临停业清算。

董事个人责任: 参与该壳公司安排的普通合伙人和任何董事，可能被命令支付赔偿款、被取消董事资格、被禁止通过旅行禁令离开直布罗陀，并且因虚假陈述行为可能面临最高两年监禁。
反洗钱/金融制裁

法定制裁: 根据2015年《犯罪所得法》和2018年《制裁与反洗钱法》：可处以无限额罚款、没收全部财产的判决，以及最高十四年的监禁。

董事个人责任: 董事、经理人员及具有重大洗钱风险的人员可能面临个人刑事责任、民事赔偿、GFSC许可被撤销、旅行禁令以及向王室作出赔偿令。
转让定价 / 误报

法定制裁: 转移定价调整加上利息，还有最高可达未缴税款100%的税务惩罚，以及必须提交修正后的申报表；故意虚假报告将依据《刑事司法（欺诈）法》面临刑事起诉。

董事个人责任: 签署存在重大误导性申报的董事，须就额外税款和罚款承担个人责任；若虚假申报属于欺诈性逃税计划的一部分，法院还可发出禁止履职、禁止出境及监禁等处罚决定。
